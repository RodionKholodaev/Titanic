# Titanic: правила проекта

Учебное решение Kaggle Titanic. Данные: `data/train.csv`, `data/test.csv`.

## Структура
- `src/prep.py`: загрузка и подготовка данных (`build()` возвращает X_train, y_train, X_test, full).
- `src/cv.py`: фиксированный CV (`evaluate`) и логирование (`log_experiment`).
- `run_experiment.py`: запуск экспериментов.
- `experiments.csv`: журнал экспериментов.
- `tests/`: pytest.

## Правила (соблюдать во всех задачах)
- CV фиксирован: `RepeatedStratifiedKFold(n_splits=5, n_repeats=5, random_state=42)`, метрика accuracy. Не менять.
- Признаки без таргета считаются по train+test вместе.
- Всё, что использует таргет, считается только внутри фолда через трансформер в sklearn Pipeline. Никаких вычислений с `Survived` до разбиения на фолды.
- Статистики для импутации (медианы, моды) считаются только по train-части.
- Каждый эксперимент дописывает строку в `experiments.csv`.
- Решения принимаются по CV, не по лидерборду.
- Код короткий, без копипасты и лишних абстракций, пути относительные.
- Каждая задача заканчивается зелёным `pytest`.
